# Editorial Skills

I built these Claude skills for my team. We use them to edit and check product review pages at SelectHub. 

| Skill | What it does |
|---|---|
| [zac-edits-pdp](skills/zac-edits-pdp) | Line-edit review of product page copy, based on common edits I make. Includes a mechanical scan for promotional words, hedges, filler and passive voice. |
| [pdp-template-check](skills/pdp-template-check) | Pass/Fix checklist of a draft against the product page template. |
| [pdp-reader-relevance](skills/pdp-reader-relevance) | Checks which parts of a draft could be more relevant for readers based on SelectHub buyer research data. |
